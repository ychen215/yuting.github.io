# Yuting Chen — Academic Website

This folder is ready to publish with GitHub Pages. It contains a one-page research profile and the current application-ready CV.

## Publish from a personal GitHub Pages repository

1. Create or open the repository named `ychen215.github.io`.
2. Upload the contents of this folder to the repository's main branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select **main** and **/(root)**.
5. Save. The site will appear at `https://ychen215.github.io/`.

All website links are relative, so the same files also work inside an ordinary project repository.

## Keeping the site current

- Add the final year, volume, pages, and DOI for the accepted JRSS Series A article when they become available.
- Replace the CV file in `assets/` whenever the CV is updated.
