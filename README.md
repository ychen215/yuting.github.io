# Yuting Chen — Academic Website

This folder is ready to publish with GitHub Pages. It contains a one-page research profile and the current application-ready CV.

## Published website

The site is published from the `main` branch of the public repository
`ychen215/yuting.github.io`, using the repository root as the GitHub Pages source.

Live site: `https://ychen215.github.io/yuting.github.io/`

All website links are relative, so the same files also work inside an ordinary project repository.

## Keeping the site current

- Replace the CV file in `assets/` whenever the CV is updated.
